## The AIOS method

Every system I build follows four layers that turn scattered tools into one operating system:

1. **Context** - what the system knows: business data, documents, priorities, rules
2. **Connections** - what it can reach: live tools (CRM, email, calendar, sheets) wired in at the source
3. **Capabilities** - what it can produce: qualified leads, drafted replies, reports, decisions
4. **Cadence** - what runs on its own: daily, weekly, and event-driven automations
